# 思辨学堂比赛演示入口

本文件夹是独立的公网演示启动工具。平台界面、智能体和教学流程沿用 `../six-arts-web`，没有改动原项目源代码。比赛演示账号及成绩放在本目录 `.local/app-data/`，与原先本机使用的数据分开。

## 启动与配置

1. 双击 `启动比赛演示.cmd`，保持窗口运行。需要 Node.js 24 或以上版本。
2. 在这台电脑打开 http://127.0.0.1:3212/ ，进入“模型设置”填写并测试现有千问配置。密钥保存在进程内存中，关闭此服务后需要重新配置。
3. Cloudflare 隧道使用 `sibianxuetang-demo`。添加“已发布的应用”路由：域名 `sibianxuetang.cn`，子域名留空，服务类型 HTTP，服务地址 `127.0.0.1:3211`。如果页面没有单独的类型选择，填写完整地址 `http://127.0.0.1:3211`。
4. 公网路由生效后，打开本目录 `老师访问链接.txt`，将其中的直接访问链接提供给评审。该链接包含演示访问码，请勿放进开源仓库。
5. 用手机移动网络打开评审链接，实际测试页面与一次模型回复，确认外网可用后再提交。

## 地址用途

| 地址 | 用途 |
| --- | --- |
| http://127.0.0.1:3212/ | 本机管理、配置模型，不能填入 Cloudflare 的路由 |
| http://127.0.0.1:3211/ | 受保护的演示入口，Cloudflare 必须指向这里 |
| https://sibianxuetang.cn | 配好 Cloudflare 后的公网入口 |

公网访问需要演示访问码；通过“直接访问链接”可自动进入。公网不能修改模型设置或执行后端重启。原项目的 http://127.0.0.1:3210/ 是独立的本机入口，不由本工具启动。

## 比赛期间

- 电脑须开机、联网、保持此服务运行，并避免进入睡眠。cloudflared 已安装为自动启动的 Windows 服务；这并不等于平台后端也会自动启动。
- 默认最多同时处理 3 个模型操作，每天最多放行 300 次需要模型的演示操作。一次操作可能包含多次模型请求，该限制不是模型 token 预算或费用硬上限。模型费用仍按服务商用量结算。
- 访问码与每日用量分别保存在 `.local/demo-settings.json`、`.local/demo-usage.json`。修改设置后须重新启动演示服务。
- 需要结束时，在启动窗口按 Ctrl+C。之后公网将无法正常使用平台。比赛结束后也可在 Cloudflare 控制台删除本演示路由。
- 对话生成、图片生成速度还取决于模型与网络。首次上线后应使用比赛现场的真实网络进行一次完整演练。

## 检查

网关检查：`node --test gateway.test.mjs`。原平台检查在 `six-arts-web` 目录执行 `node --test`。

不要将 `.local` 文件夹或 `老师访问链接.txt` 打包公开。原平台 `.env`、账号数据也不应进入公开源码包。

# 课程 PDF 放置位置

教材原 PDF 与其他课程 PDF 不包含在本源码仓库中。请使用你有权使用的课程资料。

当前网页教材原页定位所需主文件：

`批判性思维 王彦君编 北京高等教育出版社2020.03.pdf`

将文件放在本目录，保持文件名不变。教材印刷页码与 PDF 页码存在 7 页偏移，不能用任意其他版本替代后仍沿用原页码。

`six-arts-web/data/textbook-pages.json` 是项目已经整理的课程 OCR 检索数据；SQLite 检索索引由程序在本机自动建立。它不替代教材原页的 PDF。若改用其他版本，应重新整理 OCR、章节页码、课程条目与习题来源。

完整测试还会检查 `six-arts-web/course-library.mjs` 的 `documents` 中列出的 9 份课程资料。未准备这些 PDF 时，执行 `npm test`（根目录）或 `npm run test:code`（源码目录）进行代码检查；准备齐全后再执行完整测试。
